# Paradise Nursery

Aplikasi keranjang belanja toko tanaman hias online **Paradise Nursery**, dibangun dengan React, Redux Toolkit, dan Vite.

## Fitur
- Halaman utama dengan gambar latar, nama perusahaan, tombol "Mulai", dan bagian Tentang Kami
- Daftar produk: 3 kategori x 6 tanaman (thumbnail, nama, harga)
- Tombol "Tambahkan ke Keranjang" (nonaktif setelah ditambahkan) dan ikon keranjang dengan jumlah dinamis
- Navbar (Beranda, Tanaman, Keranjang) di halaman Daftar Produk dan Keranjang
- Keranjang: tambah/kurangi jumlah, hapus item, total biaya per tanaman, total keseluruhan, Checkout ("Segera Hadir"), dan Lanjutkan Berbelanja

## Menjalankan
```bash
npm install
npm run dev
```
